# JuliaWeb Security Policy

## Supported Julia Versions

The LTS and current stable releases of Julia are the ones supported for security updates.

| Julia Version | Supported          |
| ------------- | ------------------ |
| LTS           | :white_check_mark: |
| Stable        | :white_check_mark: |
| < 1.0         | :x:                |

## Reporting a Vulnerability in JuliaWeb packages

Please report security vulnerabilities in JuliaWeb packages by emailing security@julialang.org.
